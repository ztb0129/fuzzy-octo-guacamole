# 实训室选拔程序 · 数据库表结构设计

基于 `PRD.md`（MySQL 8.0，utf8mb4）。设计原则：

1. **窗口配置驱动**：所有时间窗存表，不硬编码（PRD 技术约束）。
2. **名单与确认分离**：老师产出名单（提交即快照），系统基于名单生成录取通知与确认任务，状态各自流转。
3. **名额强一致**：占用名额的写操作走事务 + `lab_quotas` 行锁，防止超员（T4.3 / A6.2 校验的落点）。
4. **全量留痕**：`audit_logs` 记录操作人/时间/对象/前后值，只插不删（A8）。
5. **轮次隔离**：志愿、名单、录取、确认均带 `round_no`，历史轮只读可回看（T6.2）。

## 表总览

| 分组 | 表 | 说明 |
|------|----|------|
| 账号 | `users` `students` `teachers` | 统一账号 + 角色扩展信息 |
| 基础数据 | `labs` `lab_staff` | 实训室（名额统一链路的载体） |
| 流程配置 | `stage_windows` `settings` | 8 环节 + 三轮补录 + 递补确认窗口 |
| 志愿 | `wish_forms` `wish_items` | 平行志愿与调剂意愿（按轮） |
| 面试 | `interviews` `interview_records` | 场次与四维度评价 |
| 名单 | `lab_lists` `list_members` | 三张名单 + 退回/重开通道 |
| 录取与确认 | `admission_offers` `confirmations` `lab_quotas` | 拟录取/递补/安置通知、学生确认动作、名额占用 |
| 调剂 | `adjust_pool` | 三级优先级 + 对账兜底清单 |
| 终局 | `student_states` `final_results` `publications` | 学生状态机、最终名单、公示 |
| 通知与留痕 | `announcements` `notices` `audit_logs` | 公告、站内消息、操作日志 |

## DDL

### 账号

```sql
CREATE TABLE users (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  account       VARCHAR(64)  NOT NULL UNIQUE COMMENT '学号/工号/管理员账号',
  password_hash VARCHAR(255) NOT NULL,
  real_name     VARCHAR(32)  NOT NULL,
  role          ENUM('student','teacher','admin') NOT NULL,
  status        ENUM('active','disabled') NOT NULL DEFAULT 'active',
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE students (
  user_id       BIGINT UNSIGNED PRIMARY KEY,
  student_no    VARCHAR(32) NOT NULL UNIQUE,
  class_name    VARCHAR(64) NOT NULL,
  phone         VARCHAR(20) NULL COMMENT '首次登录强制核对后写入（S0）',
  phone_verified TINYINT(1) NOT NULL DEFAULT 0,
  batch_year    SMALLINT NOT NULL COMMENT '届次，首版仅一届（暂不做多届）',
  FOREIGN KEY (user_id) REFERENCES users(id)
);

CREATE TABLE teachers (
  user_id   BIGINT UNSIGNED PRIMARY KEY,
  staff_no  VARCHAR(32) NOT NULL UNIQUE,
  FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### 基础数据

```sql
CREATE TABLE labs (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  name          VARCHAR(64)  NOT NULL,
  direction     VARCHAR(255) NOT NULL COMMENT '项目方向',
  intro         TEXT NULL COMMENT '培养安排与考核要求',
  capacity      INT UNSIGNED NOT NULL COMMENT '招录名额（老师填报提交）',
  status        ENUM('draft','published','archived') NOT NULL DEFAULT 'draft',
  published_by  BIGINT UNSIGNED NULL COMMENT '审核发布的管理员（A0.3 统一链路）',
  published_at  DATETIME NULL,
  FOREIGN KEY (published_by) REFERENCES users(id)
);

CREATE TABLE lab_staff (
  lab_id    BIGINT UNSIGNED NOT NULL,
  user_id   BIGINT UNSIGNED NOT NULL COMMENT '绑定老师',
  lab_role  ENUM('lead','member') NOT NULL COMMENT '室负责人可提交名单，普通老师仅录评分（T0.1）',
  PRIMARY KEY (lab_id, user_id)
);
```

### 流程配置

```sql
CREATE TABLE stage_windows (
  id        BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  stage     ENUM('briefing','openday','wish','interview','confirm',
                 'waitlist_confirm','makeup_wish','makeup_interview',
                 'makeup_confirm','adjust','placement_confirm','publication') NOT NULL,
  round_no  TINYINT UNSIGNED NULL COMMENT 'NULL=首轮/全局；2、3=补录轮（S6/A5 轮次隔离）',
  start_at  DATETIME NOT NULL,
  end_at    DATETIME NOT NULL,
  sort      INT NOT NULL,
  UNIQUE KEY uk_stage_round (stage, round_no),
  CONSTRAINT chk_window CHECK (end_at > start_at)
);
-- 时序合法性校验（A0.4）在服务层：makeup 轮 2.start_at > confirm(轮1).end_at 等。

CREATE TABLE settings (
  `key`       VARCHAR(64) PRIMARY KEY,
  `value`     VARCHAR(255) NOT NULL,
  updated_by  BIGINT UNSIGNED NULL,
  updated_at  DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
-- 预置键：waitlist_confirm_default_hours='2'（A0.4 递补确认窗口默认值）
--        publication_days='1'（公示时长）；提醒提前量 '30,5' 分钟（S 贯穿约定）
```

### 志愿

```sql
CREATE TABLE wish_forms (
  id               BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  student_id       BIGINT UNSIGNED NOT NULL,
  round_no         TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '1=意向填报，2/3=补录',
  internal_adjust  TINYINT(1) NOT NULL DEFAULT 0 COMMENT '服从实训室内部调剂',
  cross_adjust     TINYINT(1) NOT NULL DEFAULT 0 COMMENT '服从全院跨实训室调剂',
  status           ENUM('draft','submitted','locked') NOT NULL DEFAULT 'draft',
  submitted_at     DATETIME NULL,
  locked_at        DATETIME NULL COMMENT '到点自动锁定/管理员锁定（S3.4/A2.2）',
  UNIQUE KEY uk_student_round (student_id, round_no),
  FOREIGN KEY (student_id) REFERENCES students(user_id)
);

CREATE TABLE wish_items (
  id        BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  form_id   BIGINT UNSIGNED NOT NULL,
  lab_id    BIGINT UNSIGNED NOT NULL,
  seq       TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '恒为1：平行志愿不分先后，仅保留字段占位',
  UNIQUE KEY uk_form_lab (form_id, lab_id),
  CONSTRAINT chk_max3 CHECK (
    (SELECT COUNT(*) FROM wish_items w2 WHERE w2.form_id = form_id) <= 3
  ),
  FOREIGN KEY (form_id) REFERENCES wish_forms(id),
  FOREIGN KEY (lab_id) REFERENCES labs(id)
);
-- 注：MySQL 不支持表级 CHECK 子查询，3 个上限在服务层校验；0 志愿+勾调剂=只接受调剂（S3.5）合法。
-- 未填报学生截止后由系统写 status='locked' 空壳记录或 student_states 记 not_participated（S3.5/A5.1）。
```

### 名单（三张名单 + 退回通道）

```sql
CREATE TABLE lab_lists (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  lab_id        BIGINT UNSIGNED NOT NULL,
  round_no      TINYINT UNSIGNED NOT NULL DEFAULT 1,
  status        ENUM('draft','pending_effect','effective','returned','locked')
                NOT NULL DEFAULT 'draft'
                COMMENT 'draft→pending_effect（提交）→effective（学院生效）/returned（退回）；窗口过后或生效转 locked（T4.4/A3）',
  submitted_by  BIGINT UNSIGNED NULL COMMENT '室负责人 user_id',
  submitted_at  DATETIME NULL,
  force_reason  VARCHAR(500) NULL COMMENT '校验不通过强制提交的理由（T4.3）',
  return_reason VARCHAR(500) NULL COMMENT '管理员退回原因（A3.2）',
  reopened_until DATETIME NULL COMMENT '退回后临时重开的编辑截止（T4.4/A3.2）',
  returned_by   BIGINT UNSIGNED NULL,
  effective_at  DATETIME NULL COMMENT '发布拟录取结果时置位（A3.3）',
  UNIQUE KEY uk_lab_round (lab_id, round_no),
  FOREIGN KEY (lab_id) REFERENCES labs(id)
);

CREATE TABLE list_members (
  id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  list_id     BIGINT UNSIGNED NOT NULL,
  member_type ENUM('pre_admit','waitlist','internal_adjust') NOT NULL
              COMMENT '拟录取/递补（含顺位）/内部调剂候选',
  student_id  BIGINT UNSIGNED NOT NULL,
  rank_no     SMALLINT UNSIGNED NULL COMMENT '仅 waitlist 使用，拖拽排序结果（T4.2）',
  UNIQUE KEY uk_list_type_student (list_id, member_type, student_id),
  UNIQUE KEY uk_waitlist_rank (list_id, rank_no),
  FOREIGN KEY (list_id) REFERENCES lab_lists(id)
);
-- 服务层校验（T4.3 双向核对）：
--   pre_admit 人数 ≤ lab_quotas.remaining；waitlist 不含 pre_admit 成员；
--   internal_adjust 成员须 wish_forms.internal_adjust=1；
--   正向对账：报名本室且 internal_adjust=1 但未进任何名单 → 供 A6 对账清单。
```

### 录取通知与确认（S5 自动分流、递补链、改投）

```sql
CREATE TABLE admission_offers (
  id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  student_id  BIGINT UNSIGNED NOT NULL,
  lab_id      BIGINT UNSIGNED NOT NULL,
  round_no    TINYINT UNSIGNED NOT NULL DEFAULT 1,
  source      ENUM('pre_admit','waitlist_promote','placement') NOT NULL
              COMMENT '首轮拟录取/递补顺位补位/调剂安置（S5.3、A6）',
  status      ENUM('pending','auto_confirmed','chosen','declined_by_switch',
                   'timeout_waived','cancelled') NOT NULL DEFAULT 'pending'
              COMMENT 'pending=多录取待自选；auto_confirmed=仅1个自动确认；chosen=学生点选；'
                     'declined_by_switch=改投他室被释放（S5.4）；timeout_waived=超时放弃；'
                     'placement 超时不自动置此态，转 adjust_pool 待处理（S7.2）',
  deadline_at DATETIME NULL COMMENT 'confirm 窗口或递补确认窗口截止（A0.4）',
  decided_at  DATETIME NULL,
  promoted_from_offer_id BIGINT UNSIGNED NULL COMMENT '递补链/改投链的来源 offer，链式留痕（S5.4）',
  UNIQUE KEY uk_student_lab_round_source (student_id, lab_id, round_no, source),
  FOREIGN KEY (student_id) REFERENCES students(user_id),
  FOREIGN KEY (lab_id) REFERENCES labs(id)
);

CREATE TABLE confirmations (
  id          BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  student_id  BIGINT UNSIGNED NOT NULL,
  offer_id    BIGINT UNSIGNED NOT NULL,
  action      ENUM('auto','select','reselect','switch','confirm_placement') NOT NULL
              COMMENT '自动确认/首次点选/窗口内改选/改投他室递补/安置确认',
  chosen_lab_id BIGINT UNSIGNED NOT NULL,
  acted_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (offer_id) REFERENCES admission_offers(id)
);
-- confirmations 为追加流水；当前有效去向 = admission_offers 中 status∈(auto_confirmed,chosen) 的唯一记录，
-- 服务层用唯一性保证「唯一去向」：同一学生同一时点至多一条有效 offer（事务内校验）。

CREATE TABLE lab_quotas (
  lab_id        BIGINT UNSIGNED PRIMARY KEY,
  round_no      TINYINT UNSIGNED NOT NULL DEFAULT 1,
  capacity      INT UNSIGNED NOT NULL COMMENT '生效名额快照（发布时自 labs 拷贝）',
  occupied      INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '当前已占（确认+安置）',
  pre_admit_cnt INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '拟录取占用中（未确认）',
  remaining     INT UNSIGNED GENERATED ALWAYS AS (capacity - occupied - pre_admit_cnt) STORED,
  updated_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (lab_id, round_no)
);
-- 所有增减走 SELECT ... FOR UPDATE 行锁；A6.2 安置、T4.3 校验、剩余名额看板（A5.1）都读此表。
```

### 调剂池（A6）

```sql
CREATE TABLE adjust_pool (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  student_id    BIGINT UNSIGNED NOT NULL,
  priority      ENUM('internal','cross','unwilling') NOT NULL
                COMMENT '第一优先级=内部调剂候选/第二=跨室调剂/第三=未服从调剂约谈对象',
  source_lab_id BIGINT UNSIGNED NULL COMMENT '内部调剂来源室（取自 internal_adjust 名单）',
  reconcile_flag TINYINT(1) NOT NULL DEFAULT 0
                COMMENT '1=对账兜底：勾了内部调剂但未进任何候选名单，并入第一优先级末尾（T4.3/A6.1）',
  status        ENUM('pending','placed_pending_confirm','confirmed','timeout_pending',
                     'waived','archived') NOT NULL DEFAULT 'pending'
                COMMENT 'timeout_pending=安置确认超时，不自动递补不自动判放弃，管理员手动登记终局（A6.3/S7.2）',
  placed_lab_id BIGINT UNSIGNED NULL,
  deadline_at   DATETIME NULL COMMENT 'placement_confirm 窗口截止（A0.4）',
  interview_note VARCHAR(500) NULL COMMENT '第三优先级线下面谈结果登记（A6.3）',
  operated_by   BIGINT UNSIGNED NULL COMMENT '安置操作管理员',
  UNIQUE KEY uk_student (student_id),
  FOREIGN KEY (student_id) REFERENCES students(user_id),
  FOREIGN KEY (placed_lab_id) REFERENCES labs(id)
);
```

### 通知与留痕

```sql
CREATE TABLE announcements (

  title       VARCHAR(128) NOT NULL,

  audience    SET('student','teacher','admin') NOT NULL DEFAULT 'student',

CREATE TABLE notices (

  user_id    BIGINT UNSIGNED NOT NULL,
  biz_type   ENUM('interview','offer','waitlist_promote','switch_release',
                  'placement','deadline_reminder','round_open','publication') NOT NULL,
  payload    JSON NOT NULL COMMENT '渲染所需最小字段（lab、deadline、offer_id…）',

CREATE TABLE audit_logs (
  id           BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  actor_id     BIGINT UNSIGNED NOT NULL,
  action       VARCHAR(64) NOT NULL COMMENT '如 list.return / quota.place / window.reopen / publication.revoke',
  target_type  VARCHAR(32) NOT NULL,
  target_id    BIGINT UNSIGNED NOT NULL,
  before_json  JSON NULL,
  after_json   JSON NULL,
  affected_cnt INT UNSIGNED NULL COMMENT '推进类操作弹窗展示的受影响人数（A8）',
  created_at   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_target (target_type, target_id),
  KEY idx_actor_time (actor_id, created_at)

```

## 关键规则 → 表/约束映射

| PRD 规则 | 落点 |
|----------|------|
| 3 个平行志愿不分先后（S3） | `wish_items` 唯一键去重 + 服务层 ≤3；`seq` 恒 1 |
| 两项调剂意愿独立、按轮可重勾（S3/S6.2） | `wish_forms.internal_adjust / cross_adjust`，按 `round_no` 一行 |
| 单拟录取自动确认 / 多拟录取限时自选（S5/A3.3） | 生效时批量生成 `admission_offers`：仅 1 条→直接 `auto_confirmed`；≥2 条→`pending` + `deadline_at` |
| 超时放弃→按顺位递补→耗尽滚下一轮（S5.3 统一口径） | 定时任务：`pending` 超时置 `timeout_waived`，按 `list_members.rank_no` 生成 `waitlist_promote` offer（`promoted_from_offer_id` 记链）；耗尽后 `lab_quotas.remaining` 滚入下轮 |
| 已确认学生改投递补、链式释放（S5.4） | 新 offer 确认时原 offer 置 `declined_by_switch`，`confirmations.action='switch'`，同事务触发原室顺移 |
| 名单退回 + 临时重开窗口（T4.4/A3.2） | `lab_lists.status='returned'` + `reopen_reason/reopened_until`，重开期内可再提交 |
| 名额不超员（T4.3/A6.2） | `lab_quotas` 行锁 + `remaining` 生成列校验，事务内增减 |
| 调剂三级优先级 + 对账兜底（A6.1） | `adjust_pool.priority` + `reconcile_flag` |
| 安置超时手动登记终局（S7.2/A6.3） | `adjust_pool.status='timeout_pending'`，终局由 `placed/waived/archived` 人工流转 |
| 唯一去向 | `final_results` 学生唯一 + 有效 offer 至多一条（服务层事务） |
| 公示撤回重发重新计时（A7.2） | `publications.status` 流转 + 新记录新 `start/end` |
| 操作日志不可删（A8） | `audit_logs` 只插 + 库权限限制 |

## 权限视图（应用层 + 库层双保险）

- 老师：`lab_lists/list_members/interview_records/admission_offers` 查询一律带 `WHERE lab_id = 本人绑定室`；仅 `lead` 可写名单（`lab_staff.lab_role`）。
- 学生：只读自己相关行；`wish_items` 对他人的可见性由 API 层屏蔽（老师端仅聚合数字，T3.1）。
- 管理员：全院读写，但终局类操作（生效、推进、安置、公示）强制走 `audit_logs` 写入的同一事务。
